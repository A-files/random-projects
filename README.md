## 🚀 Milestone 1: Variables & Data Types (`basics.py`)
My first ever script explores how Python handles and validates different kinds of information under the hood. 

### What I Covered:
* **Strings (`str`):** Handling textual data.
* **Booleans (`bool`):** Working with True/False logic flags.
* **Integers (`int`) & Floats (`float`):** Differentiating whole numbers from decimals.
* **Type Validation:** Utilizing `isinstance()` to programmatically verify data types.
